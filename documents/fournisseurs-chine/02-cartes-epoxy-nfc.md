La surcharge commerciale actuelle de +3€ pour "format carte" est donc largement cohérente et laisse une marge nette suffisante même à MOQ bas (500-1000 unités).

## Facteurs Clés pour Décision

### 1. **Format Définitif Requis**
- **Carte visite standard (85×54mm)** → Sunlanrfid, Yeridi, Sunrise Smart (priorité).
- **Badge rond/custom** → Sunrise Smart (30mm), Yanming (custom dôme).
- **Petit badge (40×25mm)** → FOCUS RFID (optimal).

### 2. **Volume Initial**
- **Pilot 500–1000 unités** → Yeridi (MOQ 50) ou Sunlanrfid.
- **Volume 5000+** → Sunlanrfid (prix dégressif majeur : $0.20 → $0.11).

### 3. **Impression Logo / Branding**
Tous proposent impression custom ; vérifier :
- Résolution CMYK requise (200 DPI minimum pour petit texte).
- Délai gravure laser si logo métal/gravé.
- Coût surcharge logo (souvent inclus, parfois +$0.01–0.05).

### 4. **Délai Production**
- Standard : 7–12 jours usine + 2–5 jours expédition express.
- Pour urgence < 7 jours : confirmer capacité préalable (non standard).

### 5. **Certifications & Garantie**
- **ISO 9001 requis ?** → Sunlanrfid, FOCUS RFID, Goldbridge (standard).
- **Garantie produit ?** → Goldbridge affiche 2–3 ans.
- **RoHS/CE ?** → Vérifier avec fournisseur sur devis.

## Points d'Attention (Risques Identifiés)

1. **Puce NTAG Authentique** → Vérifier que puce n'est pas clone/contrefaçon. Demander certificat de conformité NXP.
2. **Délai Express Fiable** → Fournisseurs promettent souvent "7 jours" usine mais ne comptent pas douanes/congestion ports.
3. **Qualité Époxy** → Épaisseur dôme bombée peut varier ; demander spec technique précise (épaisseur mm, matière résine).
4. **MOQ vs Palette** → MOQ 500 ≠ 1 palette ; clarifier si 500 = commande viable ou nécessite surstock.
5. **Impression Durabilité** → Vérifier si impression CMYK supporte bien frottement (test friction 500 cycles minimum).
