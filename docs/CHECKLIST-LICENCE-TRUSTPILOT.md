# Trustpilot — vérification avant commercialisation

Mise à jour : 8 septembre 2026

Le simple fait de posséder une clé API ne prouve pas que Caela peut redistribuer ou afficher les avis de plusieurs commerçants dans son propre produit.

Avant d'activer Trustpilot en production :

- obtenir pour Caela un accord d'intégration partenaire ou une confirmation écrite couvrant l'usage multi-clients ;
- vérifier que chaque commerçant possède le niveau Trustpilot Business et le module API requis ;
- faire confirmer le droit de répondre, stocker et afficher les avis dans Caela ;
- utiliser les widgets officiels lorsque les droits de copie et d'affichage ne sont pas expressément accordés ;
- synchroniser les modifications et suppressions demandées par Trustpilot dans le délai contractuel applicable ;
- interroger l'API Deletions au moins tous les 28 jours si des avis sont conservés ;
- respecter les règles de marque, d'attribution et de logo Trustpilot ;
- conserver le contrat, le numéro de partenaire et la réponse écrite dans le registre Caela.

Contacts et documentation :

- Introduction API : https://developers.trustpilot.com/introduction/
- Module API : https://developers.trustpilot.com/api-module-overview/
- Règles de marque : https://corporate.trustpilot.com/legal/for-businesses/legal-brand-guidelines/sept-2026
